Reading this lot’s report

On lot DPS-9368773 the laboratory reports BPC-157 at 99.36% purity with a measured quantity of 4.95 mg, and TB-500 at 99.19% purity with a measured quantity of 4.97 mg. Because the product contains two peptides, read each line against its own labeled amount (5 mg each) rather than against the 10 mg combined.

What the public report does not show

The COA library lists this report as UPLC/MS covering purity, identity and quantitation. No separate endotoxin, sterility, elemental-impurity or residual-solvent report is published for lot DPS-9368773 as of 2026-10-10. Renvara states a seven-point program; this page does not claim that this lot passed all seven. See what each test measures, or how to read a COA.

Questions about this lot

Which lot does the public report cover?

Lot DPS-9368773, analyzed 2026-09-16 by Horizon Analytical as report 1028861. Only this lot is public as of 2026-10-10. A report for one lot does not describe another lot.

What does the measured quantity compare with?

The report lists a measured quantity for each component; compare it with the labeled strength (5 mg + 5 mg). This site does not calculate an accuracy figure, so read the original PDF for the method and tolerance.

Why are there two purity numbers?

The vial holds two peptides, so the laboratory reports each component separately. Each has its own purity percentage and measured quantity on report 1028861.
