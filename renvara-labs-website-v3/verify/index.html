Four checks, in order

To verify a lot, read the lot number on the vial label, find the report with the same product, strength and lot number in the COA library, open the PDF on the laboratory's own site, and confirm the analyzed date and method. A report only describes the lot it names.

Show the steps: Four checks, in order
  1. Read the vialFind the lot or batch number on the label. Note the product name and labeled strength.
  2. Match the reportFind the same product, strength and lot in the COA library.
  3. Open the lab linkThe PDF is hosted by Horizon Analytical, not by this site.
  4. Check the detailsConfirm the analyzed date, the method and the results listed on the report.

Check a lot number

This lookup runs in your browser over the six public lots in the COA library. It does not query a database, and nothing is sent anywhere.

Digits alone also work, for example 6373036.

If something does not match

If the lot is not listed, the product or strength differs, or the analyzed date looks wrong for your vial, do not assume the report applies. Email support@renvaralabs.com with the product name, the lot number and your order number. Support can help locate the documentation that exists for your lot.
