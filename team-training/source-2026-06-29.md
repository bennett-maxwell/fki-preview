Deep-dive — Issue #1 (audio kept getting blocked):
- Issue: The daily recording failed a few days running.
- Example/evidence: The logs show "Google daily audio limit" — an instant block, not a login problem.
- Root cause: Google caps how much free audio one account can make per day. We hit the cap.
- Correct behavior: Make the audio from a live, signed-in run, and try again after the daily limit resets. If it is still capped, ship the written training and the player now, and add the audio when the limit clears — never fake a "done."
- Exact words to say next time: "If the audio is blocked by the daily limit, ship the written version and the player now, and add the audio once the limit resets."

Deep-dive — Issue #3 (jobs running on the wrong day):
- Issue: The training emailed on Saturday and Sunday when it should only run Monday through Friday.
- Example/evidence: Two extra "FKI AI Training" emails dated 06-27 and 06-28.
- Root cause: A timer was set to run every day instead of only workdays.
- Correct behavior: When a job should only run on certain days, the timer must check the day first and skip the rest.
- Exact words to say next time: "This job ran on a day it should skip — make the timer check the day and only run on workdays."

## How AI Thinks (Agentic 20%)
Idea 1 — The hand-off (you set it, the AI finishes it):
- Plain explanation: Instead of walking the AI through every step, you hand it the whole job and what "done" looks like, then let it run and bring you the proof. That is how the lead machine found 110 batches overnight with nobody watching.
- When to use it today: Any job that is really a bunch of steps.
- Exact words to say: "Here's the whole job and what done looks like — run it and bring me the proof."

Idea 2 — Small helpers, stacked (nested sub-agents):
- Plain explanation: For a big job, the AI can make a team of mini-helpers — and each mini-helper can make its OWN mini-helpers, up to three layers deep — all working at once.
- When to use it today: When one task is really many tasks under it.
- Exact words to say: "Split this into smaller helpers and let each one split its own piece if it needs to."

Idea 3 — Copy before you build (reuse over rebuild):
- Plain explanation: A smart helper checks if the thing already exists before building a new one. The Maxx white-label page proved it — we re-skinned, we did not rebuild.
- When to use it today: Before any new build.
- Exact words to say: "Before you build this, check if we already have one I can copy."
