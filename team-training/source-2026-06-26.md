DEEP DIVE — Issue 3 (double email):
- Issue: The same report emailed twice in one morning.
- Root cause: A timer fired more than once, or two timers do the same job.
- Correct behavior: One job, one timer. When you see a double-send, ask the AI to find the duplicate timer and turn one off.
- Exact words to say next time: "This report sent twice — find the duplicate timer and shut one off so it only sends once."

## How AI Thinks (Agentic 20%)
Idea 1 — Copy before you build (reuse over rebuild):
- Plain explanation: A smart helper checks if the thing already exists before building a new one. The Maxx white-label page proved it — we re-skinned, we did not rebuild.
- When to use it today: Before any new build, ask "do we already have one of these?"
- Exact words to say: "Before you build this, check if we already have one I can copy."

Idea 2 — One job, one timer (no double-sends):
- Plain explanation: When a task runs on its own, it should run on exactly one timer. Two timers doing the same job is how you get a report sent twice.
- When to use it today: Any time you set up a job that runs by itself.
- Exact words to say: "Make sure only one timer runs this so it never fires twice."

Idea 3 — Don't say done, show proof:
- Plain explanation: "Done" is just a word. A link, a receipt, or a file is real proof.
- When to use it today: Every single task.
- Exact words to say: "Don't tell me it is done — show me the link."
