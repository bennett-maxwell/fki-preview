4. Issue: One older audit grade was too generous because it rested on the puffed-up number. — Correct behavior: re-grade honestly when the proof underneath changes.
5. Issue: A 404 (a "page not found" link) was left open in one cycle. — Correct behavior: fix or remove dead links before closing the job.

DEEP DIVE — Issue #2 (sent but not logged): This one is sneaky. The work LOOKED finished — the team got the email. But because no receipt was written, the next run thought yesterday never happened. Lesson for everyone: "sent" is not the same as "logged." If you hand a task to the helper, the last step is always proof on paper.
