The Six Agents

Built for orthopaedic trauma & extremities reps.

Each agent is tuned to a real DePuy Synthes rep workflow — case-side, in-OR, post-case admin, and the procurement back-channel. No generic SaaS-CRM autopilot dressed up in red.

AGENT 01 · SPEED-TO-LEAD

Sub-5-minute inquiry response

Surgeon, scrub lead, or procurement contact reaches out — agent triages and gets a first response back in under 5 minutes, 24/7. Replaces the current "hours" cycle.

Pain fix: Lead speed: hours → sub-5-min response window.
  • Classifies channel (email · text · Teams) + urgency
  • OR-urgent vs. elective vs. distributor routing
  • Pre-fills response with product reference + IFU link
  • Pages Alex on mobile only when human judgment needed
Stack: Email + Teams webhook · SMS via Twilio bridge · Notion task log
AGENT 02 · ADMIN WORKFLOW

Voice-to-Notion case logging

After-case voice notes from the parking lot become structured Notion records — case type, surgeon, hardware used, follow-ups. Receipts get OCR'd and filed automatically.

Pain fix: Admin work — typical rep loses 30-40% of week to logs & reports (Salesforce State of Sales, 2024).
  • Voice → transcript → Notion case template
  • Auto-categorized by surgeon, account, product family
  • Receipt photos → expense entries
  • Sterile-set checklist verification
Stack: Whisper transcription · Notion API · receipt OCR pipeline
AGENT 03 · REPORTING

Weekly pipeline + case-volume roll-ups

No CRM yet, so reporting must be assembled from Notion, email, Teams. Agent does this every Sunday night so Monday district reviews don't eat Alex's morning.

Pain fix: Reporting pain — eliminates manual weekly roll-up labor.
  • Surgeon engagement heatmap (touches per week)
  • Pipeline freshness scoring
  • Case-volume by product family
  • One-click district report export (PDF + Slack/Teams post)
Stack: Notion API · pandas pipeline · weekly cron · PDF render
AGENT 04 · TEAM ORG

Cross-team handoff with full context

Sub-rep takes a case for Alex. Scrub lead needs an instrument tray confirmation. Procurement wants a contract page. Each handoff carries the full thread.

Pain fix: Team organization — kills the context-loss tax between Teams, Text, and Email.
  • Single intake → auto-create Teams thread per case
  • SharePoint doc links attached on creation
  • Notion task hands off cleanly with owner change
  • Open-loop monitor pings 24h before silent drop
Stack: MS Graph (Teams) · SharePoint API · Notion API
AGENT 05 · OUTREACH

Compliant cold sequences for medtech

Three vertical templates — hospital procurement intro, ASC owner outreach, distributor partner re-engagement. Phrasing screened for Open Payments / Sunshine Act safety. No off-label claims.

Pain fix: Lead volume ~10/mo → measured uplift target without compromising compliance.
  • Three audience tracks (hospital · ASC · distributor)
  • Compliance-screened phrasing (no off-label)
  • Reply detection → auto-route to Agent 01
  • A/B test queue with conversion logging
Stack: Email API (SendGrid/Postmark) · reply parsing · Notion log

AGENT 01 · SPEED-TO-LEAD

Medtech inquiry triage + first-response template

You are the speed-to-lead agent for Alex Ramos's DePuy Synthes
trauma & extremities rep practice. Inputs: raw inquiry text +
channel (email/text/Teams).

Step 1 — Classify
  - urgency: OR-urgent | elective-soon | elective-future | distributor | other
  - role: surgeon | scrub_lead | OR_director | procurement | distributor | other
  - product_family (best guess): trauma_plating | IM_nail | foot_ankle |
    hand_wrist | external_fixation | power_tools | other

Step 2 — Draft a <120 word first response that:
  - acknowledges receipt within 5 minutes
  - asks at most TWO clarifying questions tied to the classified role
  - cites the relevant product family in DePuy Synthes nomenclature
  - includes the standard IFU-availability sentence (compliance)
  - signs off as "Alex Ramos — DePuy Synthes Trauma & Extremities"
  - NEVER makes off-label claims or pricing commitments

Step 3 — Page rules
  - If urgency = OR-urgent → page Alex on mobile + Teams immediately
  - If role = procurement and intent contains pricing → flag for Alex
    review before send
  - Else → queue draft for Alex's 20-minute review window

Output JSON: { urgency, role, product_family, draft_text, page_alex (bool),
flag_for_review (bool), suggested_next_step }
AGENT 03 · REPORTING

Weekly Notion → exec roll-up generator

You are the reporting agent. Input: prior 7 days of Notion case log
entries, email metadata, Teams thread counts.

Generate a one-page weekly summary with these sections:

1. WEEK SNAPSHOT
   - cases logged (count by product family)
   - surgeons touched (count, list)
   - leads received (count, source breakdown)
   - response time p50/p90 vs. last week

2. PIPELINE FRESHNESS
   - open opportunities > 14 days stale → list
   - cases awaiting follow-up > 7 days → list

3. SURGEON ENGAGEMENT
   - top 5 most-touched surgeons this week
   - top 3 cooling surgeons (touches dropped >50% vs. trailing 4 wks)

4. ALERTS
   - any compliance keyword flagged in outbound
   - any case logged without sterile-set checklist confirmation

5. NEXT WEEK FOCUS
   - 3 recommended actions for Alex, ranked by estimated impact

Tone: factual, no hype, district-manager-readable. Cite source rows
inline as Notion page IDs. Export as PDF + post to #depuy-alex-weekly
Teams channel every Sunday 9pm MT.
AGENT 05 · OUTREACH

Compliant cold-outreach template — medtech vertical

You are the outreach agent for Alex Ramos. Generate a 4-step
sequence for ONE of these tracks: HOSPITAL | ASC | DISTRIBUTOR.

Compliance rules (must follow on every message):
  - no off-label claims
  - no implied pricing commitments
  - no surgeon-targeted financial inducement language
  - product references must match cleared FDA indication
  - include opt-out phrase in step 1

Tone: clinical, evidence-based, succinct. Sub-90-word messages.

Step 1 (Day 0) — Cold intro
  - one-line credential ("Alex Ramos · DePuy Synthes Trauma &
    Extremities, [territory]")
  - one specific value pillar relevant to the recipient role
  - one open question
  - opt-out line

Step 2 (Day 3) — Value drop
  - one case study or surgeon-validated outcome (must be on-label)
  - 1-question CTA

Step 3 (Day 8) — Different angle
  - reframe value — operational vs. clinical
  - 1-question CTA

Step 4 (Day 14) — Soft close
  - acknowledge silence is fine
  - leave one resource link (peer-reviewed reference or IFU)
  - clean exit

Output: array of 4 message objects { day, subject, body, cta_question }
Reply detection: any non-bounce reply → route to Agent 01 within 5 min.
